Rating from "ingen smerte" to "ekstrem smerte". One code for each temperature program. Only difference is in the "settings" section (program name, and program duration). The duration is the same as the task duration, so that the rating ends and the rating data is downloaded immediately. iMotions program has 2 "slides": slide 1 is instructions, slide 2 is the rating HTML. The iMotions "slide" is 2 seconds longer than the offset analgesia task duration, to make sure the excel rating file has time to download.
